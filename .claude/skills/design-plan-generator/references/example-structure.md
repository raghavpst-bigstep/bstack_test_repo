This is a worked example based on a real project. Use it as a reference for how to map client inputs to the Excel rows.

## Sheet 1: Design Scope

### Activity Rows (no page type/count)

| Page Name | Sub-Features |
|-----------|--------------|
| Discovery Calls + Kick Off Calls | Gathering initial requirements + Development Plan Creation + IHCL Team Calls |
| Understanding New Requirements | Gather Information: Collect and review project briefs, IHCL Team inputs, and stakeholder feedback. Clarify Objectives: Identify project goals, target audience, and success metrics. |
| Analysis and UX Workshops | Conduct Research: Analyze user needs, behaviors, and pain points through surveys, interviews, or analytics. Facilitate Workshops: Organize collaborative sessions with stakeholders. Moodboards: Create moodboards for design concept finalization. |
| Style Guide | Define Visual Identity: Establish color palettes, typography, and iconography. Set Design Principles: Document guidelines for spacing, alignment, and grid systems. Create UI Components: Design reusable elements like buttons, forms, and cards. |
| Wireframes for Unique Pages | Sketch Layouts: Create low-fidelity sketches for key pages. Define Structure: Outline placement of headers, content, navigation, and CTAs. Focus on Usability: Ensure intuitive user interactions and accessibility. |
| Image Selection | Create Image Selection Guidelines for photographers. Select Images from DAM (provided by IHCL Team) and stock images. |
| Information Architecture | Organize content into a logical structure (sitemaps, categories). Define navigation paths and user flows for seamless interaction. |
| Functional Requirement Documents | (no sub-feature text) |

## Sheet 2: Content Scope

**Narrative:**
"There will be 20 unique pages. 21 basic screens such as Offer Detail Page, Gifting Page, Login/Join Page, etc. Two flows: My Account Flow (approximately 15-20 screens) and Booking Flow (approximately 10-15 screens). Note: Content for these flows will not be created from scratch — it will be tweaked and adapted from existing Taj or Vivanta content. We will be writing content for 5 hotels. Each hotel will have 9 hotel pages (e.g., Overview, Rooms & Suites, etc.). We will be writing content for 5 destinations and each destination will have 5 destination sub pages (experience, hotels, dining, etc.)"

**Summary table:**

| Label | Value |
|-------|-------|

| Basic Screens | 21 |
| My Account Flow | 15-20 |

## Sheet 3: Delivery Timeline

7-month project. 4 weeks per month. Gantt:

| Phase | M1 W1 | M1 W2 | M1 W3 | M1 W4 | M2 W1 | ... |
|-------|-------|-------|-------|-------|-------|-----|
| Discovery & Planning Phase 1 | ■ | ■ | ■ | ■ | ■ | ■ | (continues M2) |
| Discovery & Planning Phase 2 | | | | | | ■ | ■ | ■ | ■ | (M2 W3–M3) |
| UI/UX Design of all other Pages | (M3 onward through M6) |
| Final Feedback Implementation | (M7) |

Phase descriptions:
- **Phase 1**: Understanding the Requirements, Analysis of materials provided by the client, Brief and Debrief, Q&A Sessions and Workshop, Benchmark analysis of the market environment
- **Phase 2**: Information architecture and sitemap, Moodboard and Look & Feel for the desktop home page, UX/UI design: Home page, Hotel Overview Page, Design system (mini) (Initializing)
- **Phase 3**: UI/UX Design of all other Pages
- **Phase 4**: Final Feedback Implementation
